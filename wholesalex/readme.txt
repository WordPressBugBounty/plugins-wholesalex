== Description ==

WholesaleX is an all-in-one [B2B and wholesale plugin](https://getwholesalex.com/) for WooCommerce with AI-assisted wholesale management through MCP integration. Set role-based wholesale prices, manage wholesale pricing and discounts, approve customers and restrict store and price access with less setup complexity. 

Manage supported wholesale operations using natural language through compatible AI assistants.

The Free features below do not require a Pro license and do not expire after a trial period or usage quota. Separate add-ons are identified below.

[Documentation](https://getwholesalex.com/docs/wholesalex/getting-started/) | [Support](https://wordpress.org/support/plugin/wholesalex/)

= AI-Assisted Wholesale Management with MCP — Free =

Manage wholesale pricing, discount rules, B2B user roles and wholesale settings using natural-language prompts. WholesaleX integrates with AI assistants like ChatGPT, Claude, Gemini and many more through Model Context Protocol (MCP).

* **Wholesale Pricing and Discounts:** Create, update and manage wholesale price and discount rules.
* **Wholesale User Roles:** Create and configure B2B customer roles.
* **Wholesale Registration:** Add and manage wholesale registration fields for B2B user roles.
* **Wholesale Data:** Retrieve wholesale pricing rules, product information and B2B user roles.
* **Wholesale Settings:** Manage supported wholesale store configurations.

Control AI permissions with four access levels: Off, Read Only, Read and Write and Full Access.

= Wholesale Pricing and Price Rules — Free =

Set a wholesale price per role on product pages or create [WooCommerce wholesale pricing](https://getwholesalex.com/features/wholesale-pricing/) rules without changing regular prices for other customers.

**Wholesale Pricing Targets**

Target guests, registered customers, B2B roles, specific roles or individuals. Apply wholesale pricing to all products, selected products, categories or variations, with exclusions.

**Wholesale Price and Discount Options**

Choose wholesale pricing methods to set wholesale prices:

* **Percentage Discount:** Reduce the base price by a percentage.
* **Amount Discount:** Subtract a fixed amount from the base price.
* **Fixed Price:** Set an exact product price.

Calculate each wholesale price from the regular or sale price (General Settings). Optionally display a discount name on product pages. Schedule wholesale pricing rules with start/end dates, preview rules and role-based storefront prices and import/export pricing rules.

= Dynamic Wholesale Discount Rules — Free =

Create discount offers for selected customers and products:

* **Product Discount:** Discount products; schedule offers.
* **Cart Discount:** Use supported cart quantity, value or weight conditions.
* **Buy X Get One Discounted:** Discount one item after the required quantity is bought.

= Wholesale User Roles and Store Settings — Free =

Create wholesale customer roles for distributors, retailers, VIP buyers and other B2B groups. For each role:

* Set approval, payment and shipping methods.
* Configure tax display and exemptions.
* Automatically migrate customers at a spending threshold.
* Import/export roles.

B2C and Guest User roles cannot be deleted or converted to [B2B user roles](https://getwholesalex.com/features/user-roles/).

= Registration Forms and Customer Management — Free =

Create [registration and login forms](https://getwholesalex.com/features/wholesale-registration-form/) for WooCommerce wholesale customers with standard fields:

* Add, remove or reorder fields; combine or separate forms.
* Set automatic approval, email confirmation or manual approval, plus login behavior.
* Use the registration block or shortcodes; customize form styling.
* Edit registration, verification, approval and rejection emails in Email Templates.
* Manage approvals in Customers and role changes enabled in General Settings.
* Import/export customer CSV records in Customers.

Enable reCAPTCHA v2/v3 on supported login and registration forms with the required keys. Disabled by default; see External services for data sharing.

= Private Wholesale Store and B2B Stock — Free =

Run a WooCommerce wholesale-only [private store](https://getwholesalex.com/features/private-store/) or a hybrid B2B+B2C store. Restrict guest access to content and wholesale prices, redirect logged-out visitors, allow selected URLs and show login prompts for protected prices.

Manage separate B2B wholesale stock and display quantities, availability only or no stock information.

= Wholesale Analytics and Sales Reports — Free =

Track B2B performance in WholesaleX Analytics:

* **Sales Overview:** B2B customers, orders, total/gross sales, net revenue and average order value.
* **Sales Statistics:** Wholesale sales trends and comparisons with the previous reporting period.
* **Top Customers:** Purchase totals and customer roles.
* **Orders and Registrations:** Recent orders and pending registrations.

== External services ==

= Google reCAPTCHA =

When enabled with site and secret keys, reCAPTCHA v2/v3 loads on supported registration, login and conversation forms. Google receives the site key, IP address, browser/device details and site origin, and may use cookies. Verification sends the secret key and response token to [Google](https://www.google.com/recaptcha/api/siteverify). Disclose reCAPTCHA in your store's privacy policy.

= AI Assistants You Connect (MCP) =

The AI tools are off until an administrator turns them on. When you connect an assistant, it requests data through your site's MCP endpoint with the OAuth sign-in you approved or your application password, and the AI provider you chose receives what the assistant reads, such as rule names, product names, customer display names, WholesaleX settings and email template text, including the addresses that receive store notifications. Customer email addresses, passwords and secret keys are not returned. Review your AI provider's terms and privacy policy, and disconnect it in WholesaleX > MCP Tools or revoke its application password in Users > Profile.

[Google Terms](https://policies.google.com/terms) | [Google Privacy](https://policies.google.com/privacy) also apply when you connect Gemini.

= AI App Sign-in (OAuth) =

After an administrator enables the AI tools, OAuth sign-in and client authentication requests may download an app's public sign-in details (its OAuth client metadata document), for example https://chatgpt.com/oauth/client.json or https://claude.ai/oauth/mcp-oauth-client-metadata, to confirm the app's name and return address. This validation can happen before WordPress login or connection approval; reading store data still requires an approved administrator connection. The metadata request contains no store or customer records; the provider receives your server's IP address and WordPress's standard user agent, which contains the WordPress version and your site address. Only chatgpt.com, chat.openai.com, claude.ai, claude.com and vscode.dev are contacted, plus any host a developer adds with the `wholesalex_mcp_oauth_trusted_hosts` filter. Successful results are cached for an hour.

== Installation ==

= Requirements =

* WordPress 6.8 or later. The AI Assistant Tools (MCP) need WordPress 6.9 or later and the MCP Adapter plugin.
* PHP 7.4 or later.
* An active WooCommerce installation and a database supported by your WordPress and WooCommerce versions.

= Install from the WordPress dashboard =

1. Install and activate WooCommerce.
2. Go to Plugins > Add New and search for WholesaleX.
3. Click Install Now, then Activate.
4. Open WholesaleX to configure store mode, customer roles, registration and pricing.
5. Check your pricing and access settings with the appropriate customer account.

= Upload the plugin ZIP =

1. Download the WholesaleX plugin ZIP from WordPress.org.
2. Go to Plugins > Add New > Upload Plugin.
3. Select the ZIP, click Install Now, then Activate Plugin.

For FTP installation, extract the ZIP, upload the `wholesalex` folder to `wp-content/plugins/`, and activate WholesaleX from Plugins > Installed Plugins.

= Updating =

Back up your site and database before updating. Install available updates from the WordPress dashboard. Direct changes to plugin files may be overwritten, so keep customizations in a separate plugin or other supported extension.

If a plugin account endpoint returns a 404 after an update, go to Settings > Permalinks and save the existing settings, then check the page again.

== Frequently Asked Questions ==

= Does Free require a license? =

No. The features listed under Free work without a WholesaleX Pro license and do not expire after a trial period or usage quota.

= Can I run a B2B and B2C hybrid store? =

Yes. WholesaleX can serve wholesale and retail customers in one WooCommerce store, with pricing, payment methods, shipping methods and tax settings for different customer roles.

= Can different roles have different wholesale prices? =

Yes. Create roles for groups such as distributors, retailers or VIP customers, then assign the appropriate pricing rules. Quantity-based tiered pricing is supplied by the separate Pro add-on.

= Can rules target particular products or categories? =

Yes. Target all products, specific products, categories or variations, with product exclusions where supported by the rule.

= Can I set wholesale prices on a WooCommerce product page? =

Yes. The included role-based wholesale pricing controls are available on product pages. Tiered product pricing requires Pro.

= Are percentage, fixed-amount and fixed-price discounts supported? =

Yes. The pricing rules support percentage discounts, fixed-amount discounts and fixed prices.

= Can I schedule pricing rules? =

Yes. Set a start date, an end date or both for a pricing rule.

= Does Free include every registration field type? =

No. Free includes standard registration fields. Pro supplies additional custom field types and advanced field conditions.

= What happens to saved Pro settings when Pro is unavailable? =

Free preserves saved Pro records without running the unavailable features. Install and activate a compatible Pro add-on to use them.

= Does this plugin send customer data to a vendor service? =

WholesaleX Free does not automatically send customer or order records to WPXPO and has no automatic marketing telemetry. When enabled, reCAPTCHA sends verification tokens and technical data to Google. Opening a tutorial contacts YouTube. These services receive information such as IP addresses and browser details, as described in External services. If you connect an AI assistant to the AI tools, that assistant's provider receives the data it reads.

= Can I manage WholesaleX with an AI assistant such as Claude, ChatGPT or Gemini? =

Yes. Install the free MCP Adapter plugin, turn on WholesaleX > MCP Tools and follow the connection steps on that screen. Desktop and command-line assistants, such as Claude Desktop, Claude Code, Cursor, VS Code and Gemini CLI, connect with an application password. ChatGPT, Claude and Gemini connect with the server address and a built-in OAuth sign-in: you approve them once with an administrator account, no extra plugin needed. They connect from the internet, so your site needs a public HTTPS address. Only administrators can use the tools.

= Can I manage wholesale pricing using AI? =

Yes. WholesaleX MCP allows you to create, update and manage supported wholesale pricing and discount rules using natural-language prompts through compatible AI assistants.

= Is AI-assisted wholesale management available for free? =

Yes. WholesaleX provides free MCP tools for managing wholesale pricing rules, B2B user roles, registration fields and supported store settings. Pro-specific operations require WholesaleX Pro.

= Can I control AI access to my wholesale store? =

Yes. WholesaleX provides four MCP access levels: Off, Read Only, Read and Write and Full Access. MCP access is disabled by default.
